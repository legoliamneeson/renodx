# OpenGL DevKit target

Build target: `devkit_opengl`, for x86 or x64 Windows games. This experimental
variant uses the shared DevKit UI with OpenGL-only device selection.

See [README_OPENGL.md](../../../README_OPENGL.md) for the patched ReShade
requirement, Windows build/install commands, Original/Add-on/File workflow,
GLSL/SPIR-V formats, injection layouts, test results, and unsupported paths.
Use this addon instead of the normal DevKit, not alongside it.
